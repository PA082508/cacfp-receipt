🤖 ТРИ АГЕНТА
🏛️ ARCHITECT — Задача + Проектирование
Проектирует архитектуру · ставит задачи · следит за принципами · НЕ пишет код
Выход → заполняет Handoff: TASK · DESIGN · CONSTRAINTS · DONE_WHEN
⚙️ DEVELOPER — Логика + Реализация
Пишет код · Apps Script · HTML · SQL · следует принципам
Выход → заполняет Handoff: RESULT · FILES_CHANGED · TESTED · KNOWN_ISSUES
🎯 CONTROLLER — Контроль + Notebook
Проверяет результат · обновляет Notebook · архивирует Handoff
Выход → runRevision_() · Handoff_History · готовит следующую сессию

Порядок: ARCHITECT → DEVELOPER → CONTROLLER → повтор
